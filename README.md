
# 🐍 Snake Game

A simple, fun, and classic Snake game written in HTML, CSS, and JavaScript that you can play directly in your browser. This game features a snake that grows as it eats food and ends when it collides with the walls or itself.

## Features:

* **Play**: Start a new game with the "START" button.
* **Score**: Keep track of your score as you eat food and grow your snake.
* **Responsive**: Fully functional on desktop browsers.

## How to Play:

* Use the arrow keys (`↑`, `↓`, `←`, `→`) to move the snake.
* Every time the snake eats food (a red square), it grows, and your score increases.
* The game ends if the snake runs into the walls or itself.

## Game Controls:

* **START Play**: Starts a new game.

## Installation:

1. Clone or download this repository to your local machine.
2. Open the `index.html` file in any modern web browser to start playing the game.

```bash
git clone https://github.com/FarshidRA/Snake-Game.git
cd snake-game
open index.html
```

## Technologies Used:

* **HTML** for the structure of the game.
* **CSS** for styling and layout.
* **JavaScript** for the game logic and interactivity.
